# ClientBase PWA

Проста база клієнтів українською, адаптована для iPhone. IndexedDB, пошук, категорії, фото, телефонні посилання, імпорт/експорт JSON, офлайн-кеш.

## Опублікувати лише з iPhone через GitHub Pages

1. Зареєструйся на github.com і створи **новий приватний або публічний репозиторій**. GitHub Pages на безкоштовному тарифі для звичайного репозиторію потребує публічного репозиторію. **Не завантажуй туди справжні дані клієнтів** — тільки файли програми.
2. У Safari на github.com відкрий репозиторій, натисни **Add file → Upload files** (за потреби увімкни «Версія для комп'ютера»). Завантаж **усі шість файлів** з цієї папки в корінь репозиторію. Якщо Safari не дозволяє завантажити кілька файлів, додавай по одному.
3. Відкрий **Settings → Pages → Build and deployment → Deploy from a branch**, вибери `main` і `/ (root)`, натисни Save.
4. Дочекайся публікації. Адреса буде схожа на `https://USERNAME.github.io/REPOSITORY/`.
5. Відкрий її в Safari на iPhone, натисни «Поділитися» → «На початковий екран» → «Додати».

## Увага

- Цей архів не є вже опублікованим сайтом. Без HTTPS PWA не встановлюється належним чином та офлайн-режим не активується.
- Контакти не передаються на GitHub; вони зберігаються локально в IndexedDB конкретної інсталяції/браузера.
- Видалення вебдодатка, очищення даних сайту або збій сховища може призвести до втрати даних. Регулярно використовуй вкладку «Дані» → «Завантажити резервну копію JSON» та зберігай файл в iCloud Drive.
- Не зберігай особливо чутливу інформацію: дані не зашифровані на рівні програми. Фото стискаються і можуть займати місце.
- Офлайн-доступ працює після першого успішного завантаження на HTTPS; доступність залежить від політик зберігання iOS.
